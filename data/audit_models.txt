# This file is provenance, not configuration. "Which systems were audited" is a
# claim the thesis has to stand behind, so the list lives in version control
# next to the checklist and the probe manifest rather than in a shell command
# somebody typed once. Adding a line and re-running is the whole workflow: the
# response log keys on (probe content, model, params), so finished models cost

# do. Comparing a 7B Qwen directly against a 70B Llama would change family and
# scale together and licence no attribution at all.
